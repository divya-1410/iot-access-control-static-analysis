# Where Static Analyzers Fail on IoT Access-Control Smart Contracts

## Research Overview

This project investigates how static analysis tools detect access-control vulnerabilities in smart contracts designed for Internet of Things (IoT) environments.

The study aims to develop a labeled benchmark of access-control cases and analyze the limitations and failure patterns of static analyzers.

## Research Objectives

- Identify common access-control weaknesses in IoT-oriented smart contracts.
- Develop a clear labeling methodology for vulnerable and protected contract cases.
- Evaluate static analyzer findings against manually reviewed ground truth.
- Analyze false negatives, false positives, and limitations in vulnerability detection.
- Document the methodology, evaluation metrics, and findings transparently.

## Project Structure

- `data/` — Contract samples, benchmark cases, and evaluation datasets.
- `figures/` — Research figures and visualizations.
- `scripts/` — Analysis and evaluation scripts.
- `literature/` — Research papers and literature notes.

## Research Status

**Status:** Preliminary setup and methodology development.

Experimental results will be added only after the benchmark has been prepared, reviewed, and evaluated. No experimental findings are claimed at this stage.

## Reproducibility and Ethics

The project aims to document its methods, labeling criteria, tool configurations, and limitations so that the evaluation can be independently reviewed and reproduced.
