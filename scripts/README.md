# Research Scripts

This directory contains scripts used to prepare benchmark data, process static analyzer outputs, calculate evaluation metrics, and generate research visualizations.

## Planned Scripts

- Benchmark preparation and validation
- Static analyzer output processing
- Ground-truth comparison
- Precision, recall, and F1-score calculation
- Failure classification and summary generation

## Reproducibility

Scripts will include clear instructions and will be tested before their outputs are used in the research paper.

**Note:** No experimental results are claimed until the relevant scripts have been executed and their outputs verified.
