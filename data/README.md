# Research Data

This directory contains the smart contract samples, benchmark datasets, labeling records, and evaluation outputs used in the research project.

## Planned Contents

- `AccessControlTest.sol` — Initial test contract containing an intentionally vulnerable ownership-update function and a protected control function.
- Labeled benchmark cases — To be added after defining and validating the labeling criteria.
- Evaluation datasets — To be added after running the selected static analysis tools.

## Data Integrity

Experimental results and benchmark labels will be documented only after verification. Test examples will be distinguished from real-world smart contracts.
