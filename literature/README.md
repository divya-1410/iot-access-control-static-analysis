# Research Literature

This directory organizes the academic literature used to develop the research background, methodology, and evaluation framework.

## Key Research Areas

- Smart contract access-control vulnerabilities
- Static analysis and vulnerability detection
- IoT access-control frameworks using smart contracts
- Security benchmarks and evaluation methodologies
- False negatives, false positives, and tool limitations

## Literature Review Records

For each paper, record:

- Full title and author names
- Publication year and venue
- DOI or official URL
- Research objective and methodology
- Relevant findings and limitations
- Relevance to this project

## Research Integrity

References and research claims must be checked against the original publications. Findings from other studies must not be presented as results of this project.
